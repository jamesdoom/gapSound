# Roadmap

- Phase 0 — Foundation: initial architecture, brand, local database, migrations, validation, tests and persistent documentation implemented; verification recorded in HANDOFF.md.
- Phase 1 — Functional MVP: **in progress**. Complete and harden intelligence, KEV research, training, research notebook, source health and deterministic briefings. See TASKS.md.
- Phase 2 — Intelligence and AI: ThreatLens, optional provider abstraction, EPSS, watchlists and ATT&CK. Requires explicit user approval to start.
- Phase 3 — Learning platform: Academy, CyberRecall, spaced repetition and quizzes.
- Phase 4 — Defensive tools: deterministic synthetic SOC simulator and PhishGuard.
- Phase 5 — Application/AI security labs: static review first, isolated execution only with approval.
- Phase 6 — Hardening and portfolio: accessibility/security review, backup verification, performance and deployment readiness.

Do not implement all future modules simultaneously or deploy publicly.

Phase 1 release safeguards now include consistent backups, non-overwriting restore verification, redacted history/workspace secret scanning and dependency review. This does not close outstanding Phase 1 acceptance gates; see docs/RELEASE_ACCEPTANCE.md.

GS-007 training/notebook workflows now include configurable ordered objective plans with explicit once-per-day application. Phase 1 acceptance still requires publisher notice/reuse work, native accessibility signoff and final reconciliation.
